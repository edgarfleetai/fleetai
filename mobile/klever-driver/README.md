# Клевер Парк — мобильное приложение водителя

Изолированный Expo / React Native проект. На этом этапе **демонстрационный интерфейс** без реальной регистрации, персональных данных, платежей и бронирования. Существующий FleetAI не изменяется.

## Локальный запуск

```bash
cd mobile/klever-driver
npm install
npx expo start
```

Для проверки типов: `npm run typecheck`.

## План до полноценного запуска

1. Отдельный backend API и база для учётных записей; безопасное связывание с водителями FleetAI.
2. SMS OTP с ограничением попыток, антифродом и серверной сессией.
3. Проверка паспорта, ВУ и live-селфи через юридически согласованного KYC-провайдера; согласия, сроки хранения, аудит и разграничение доступа.
4. Каталог доступных машин и транзакционное бронирование с защитой от двойной выдачи.
5. Электронный договор, платежи, подтверждение выдачи, финансовый кабинет, заявки на ремонт.
6. Отдельная staging-инфраструктура, тесты, аудит безопасности, затем публикация iOS/Android.

**Запрещено** использовать демонстрационные экраны как реальную регистрацию или отправлять паспортные данные без утверждённого защищённого контура.
