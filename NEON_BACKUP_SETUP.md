# Бесплатное постоянное хранение базы FleetAI

Схема:

- **GitHub** хранит код.
- **Render** запускает сайт.
- **Neon PostgreSQL** хранит рабочую базу.
- **GitHub Actions** ежедневно создает резервную копию базы.

## 1. Создайте базу Neon

1. Зарегистрируйтесь в Neon.
2. Создайте проект и базу PostgreSQL.
3. Скопируйте строку подключения. Она выглядит примерно так:

```text
postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
```

Не добавляйте эту строку в файлы проекта и не публикуйте ее в GitHub.

## 2. Перенесите текущую базу

Сначала сделайте копию старой базы Render:

```bash
OLD_DATABASE_URL='СТАРАЯ_СТРОКА_RENDER' ./scripts/backup_database.sh
```

Скрипт использует переменную `DATABASE_URL`, поэтому команда в универсальной форме:

```bash
DATABASE_URL='СТАРАЯ_СТРОКА_RENDER' ./scripts/backup_database.sh
```

Затем восстановите файл в Neon:

```bash
FORCE_RESTORE=YES \
DATABASE_URL='НОВАЯ_СТРОКА_NEON' \
./scripts/restore_database.sh backups/fleetai_ДАТА.dump
```

После восстановления проверьте в Neon, что таблицы и данные появились.

## 3. Подключите Render к Neon

В Render откройте:

```text
Web Service → Environment
```

Замените значение:

```text
DATABASE_URL
```

на строку подключения Neon. Сохраните изменения и выполните Deploy.

После запуска проверьте:

- список машин;
- инвесторов;
- водителей;
- последние операции;
- добавление тестовой записи.

Старую базу Render не удаляйте, пока не убедитесь, что все данные отображаются.

## 4. Добавьте секрет для ежедневного бэкапа

В GitHub откройте:

```text
Repository → Settings → Secrets and variables → Actions
```

Создайте Repository secret:

```text
NEON_DATABASE_URL
```

В значение вставьте строку подключения Neon.

## 5. Запустите первый бэкап вручную

Откройте в GitHub:

```text
Actions → FleetAI database backup → Run workflow
```

После завершения откройте запуск. Внизу появится раздел **Artifacts** с файлом резервной копии.

Автоматический запуск настроен каждый день в **04:17 по Москве**.

## 6. Как скачать копию

```text
GitHub → Actions → FleetAI database backup → нужный запуск → Artifacts
```

Скачайте ZIP. Внутри находятся:

- `fleetai_...dump` — база;
- `fleetai_...dump.sha256` — контрольная сумма.

Артефакты настроены на хранение 30 дней. Поэтому хотя бы раз в месяц скачивайте одну копию на компьютер или облачный диск.

## 7. Как восстановить базу

Распакуйте скачанный Artifact и выполните:

```bash
FORCE_RESTORE=YES \
DATABASE_URL='СТРОКА_ЦЕЛЕВОЙ_БАЗЫ' \
./scripts/restore_database.sh fleetai_....dump
```

Внимание: восстановление с параметром `--clean` заменяет существующие таблицы в целевой базе.

## Безопасность

- Никогда не публикуйте `DATABASE_URL`.
- Если строка подключения попала в чат, скриншот или GitHub, немедленно смените пароль базы.
- Не запускайте восстановление в рабочую базу без свежей резервной копии.
