# FleetAI 3.0

Новая структура проекта, чтобы не держать всю систему в одном app.py.

## Render

Build Command:
```bash
pip install -r requirements.txt
```

Start Command:
```bash
gunicorn app:app --bind 0.0.0.0:$PORT
```

Environment:
```bash
DATABASE_URL=postgresql://...
```

## Команды для учета

Доход:
```text
703 получил 13000
703 прибыль 13000
```

Расход/ремонт:
```text
703 замена масла 2500 работа 700
```

Простой:
```text
703 простой с 11 июля по 14 июля коробка
703 стоит с 11.07 коробка
```

Инвестор:
```text
703 инвестор Иван вложил 650000 75%
```

Взаиморасчет:
```text
703 доп расходы 41700 инвестор оплатил 25000
```

## FleetAI 3.1 — водители

Исправлено:
- список автомобилей в разделе «Водители» снова заполняется из `/api/cars`;
- в списке видно, свободна машина или какой водитель уже закреплён;
- в таблице расчётов появилась кнопка «Изменить»;
- через неё можно изменить водителя, ставку, залог, день недели и ближайшую дату расчёта;
- изменение ближайшей даты перестраивает только текущий открытый недельный период и не удаляет закрытую историю.
