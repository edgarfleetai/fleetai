# FleetAI — долги водителей

Добавлено:

- отдельная база должников `driver_debts`;
- история частичных оплат `driver_debt_payments`;
- кнопка «Снять + долг» в разделе «Водители»;
- ручное указание суммы долга перед снятием водителя;
- сохранение долга после отвязки автомобиля;
- частичная оплата долга с автоматическим уменьшением остатка;
- автоматическое закрытие долга при остатке 0 ₽;
- история платежей по каждому долгу.

Новые таблицы создаются автоматически при запуске через `Base.metadata.create_all()`.
Существующие таблицы и данные не удаляются и не переписываются.

## Как использовать

1. В разделе «Водители» у нужного водителя нажмите «Снять + долг».
2. FleetAI предложит текущую расчетную сумму. Ее можно изменить вручную.
3. Укажите причину долга.
4. После подтверждения водитель снимается с автомобиля, а долг остается в разделе «Должники».
5. При поступлении денег нажмите «Частичная оплата» и укажите сумму.
6. При полном погашении запись автоматически перестает отображаться среди активных должников, но история платежей остается в базе.
